# صور المترشحين

ضع صور المترشحين في هذا المجلد بصيغة WebP مضغوطة:

- `candidate-01.webp`
- `candidate-02.webp`
- إلى `candidate-26.webp`

في `data/candidates.ts`، حدّث بيانات المترشح المقابل، مثل:

```ts
{
  id: "01",
  nameAr: "الاسم الكامل",
  rank: "01",
  photo: "/images/candidates/candidate-01.webp",
  bio: "الصفة أو نبذة تعريفية قصيرة",
}
```

يفضّل أن تكون الصور عمودية بنسبة 4:5، مع ترك الوجه ضمن الجزء العلوي من الصورة.
تظهر الصورة تلقائيًا في البطاقة والتفاصيل. عند عدم إضافة صورة، تبقى مساحة البطاقة
بتدرج لوني متناسق، ويظهر الاسم المسجل في بيانات القائمة.

## النشر والمشاركة

عرّف `NEXT_PUBLIC_SITE_URL` بعنوان الموقع المنشور، مثل `https://your-domain.dz`
لإنشاء معاينة مشاركة Open Graph صحيحة. يمكن طباعة رمز QR لهذا العنوان مع وسوم
تحليل مثل:

`?utm_source=qr&utm_medium=print&utm_campaign=hamam_debagh`

تحتاج إحصاءات عدد المسحات نفسها إلى ربط الموقع بمنصة تحليلات عند النشر.
